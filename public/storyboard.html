TGPF 2026 · Track 1 · Freshworks

The evidence contract between enterprise agents.

MCP moves verbs. ContextRail moves the case: who the subject is, which clause applies, what may not happen, and whether the systems actually changed.

“Priya starts Monday. Give her everything.”

Clear
Seven onboarding actions executed and post-checked. Paperwork gate, Freshservice ticket, pool laptop, Slack guest, onboarding checklist, manager brief, and GitHub read-only — each with a probe, not a hope.
Held
GitHub read-only on northbeam/perception-sdk waits for Security. An approval is a named human and a typed reason. It is not a deny with extra steps.
Stop
Production credentials refused under POL-CTR-001. Terminal. No queue. The clause is quoted in the capsule that every specialist still holds.

A refusal is a successful governed result. If the manager asked for “everything” and production access shipped, the system failed — even if every API returned 200.

02 · Identity is not search

The subject is fetched. Documents are searched.

The eval harness paraphrased the request (“new contract engineer starting next week”). Search returned a different evidence set. The contractor policy family never loaded. Production credentials were issued. That is the defect. The fix is architectural.

anchor lookup · not ranked retrieval

anchorworker_id W-8841 — fetched by identity, not by BM25

Search finds policy PDFs. It must not be how you decide who Priya is. If identity is a retrieval accident, governance is a retrieval accident.

03 · The object that hops

One capsule. Three specialists. Zero re-derivation.

HR, IT, and Security do not receive a summary. They receive the case: request, subject, citations, constraints, prior decisions, blockers.

04 · Denial is not a queue

The forbidden row stays on the plan. Struck through.

Issue production database credentialsSecuritydenied · POL-CTR-001
POL-CTR-001 — Contractor Onboarding Policy §4: contractors cannot receive production credentials, production database access, or customer PII exports. No approval path exists for this grant.

If a judge remembers one thing: a deny that can be approved is not a deny. ContextRail will not convert this row into a queue.
