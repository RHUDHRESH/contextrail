## What is FIXTURE

Everything. Connectors: dodo FIXTURE, hris FIXTURE, entitlements FIXTURE, github FIXTURE, slack_corpus FIXTURE, freshservice FIXTURE. Intent extraction: `heuristic` (deterministic, no model call); explanations: `template`. No network call and no LIVE system is touched. People, companies, emails, phone numbers, Slack messages, SOWs, incidents and customers are invented. Runs are recorded with source `web`: this script calls the Runner directly and renders the same RunView the doors render; it does not exercise the Slack, email, Teams or voice doors.
